# 12 · 지도 (2D 핵심) — 표준 Maps SDK · 핀 · 경로 · 지도/위성 토글

> 제품의 핵심 가치가 완결되는 화면. 표준 Google Maps Android SDK로 위치별 핀(GPS/AI 구분)과 촬영 시각순 경로 폴리라인을 그리고, 지도/위성 뷰를 전환한다.

- **Epic**: Map (핵심)
- **Depends on**: 03, 04, 10
- **PRD**: §4.4 지도 렌더, §4.6, §9 #10
- **Prototype**: MAP 화면(상단바·지도/위성 토글·위치미상 배지·핀·경로), 공용 지도 레이어

## 목표
분석 결과(또는 저장 여행)를 실제 지도 위에 핀·경로로 표시. **이 경로만으로 제품이 완결**되어야 한다(3D는 14, best-effort).

## 범위
- **In**: MapFragment(표준 Maps SDK), GPS/AI 핀 마커(시각 구분), 시각순 경로 폴리라인, 지도/위성 토글, 상단바(뒤로·제목·토글), "위치 미상 N" 배지→drawer 진입(13), 카메라 초기 fit.
- **Out**: 리플레이 재생·컨트롤·상영모드(13), 3D 비행(14), 저장/오프라인(15).

## 지도 렌더 (§4.4)
- [ ] **표준 Google Maps Android SDK**로 2D/위성 지도. `SupportMapFragment` 또는 MapView + ViewBinding.
- [ ] **핀(마커)**: 위치별 마커. **GPS 핀 vs AI 근사 위치 핀을 시각 구분** — 프로토타입: AI는 점선/반투명 + "근사 위치" 라벨, GPS는 실선·불투명. 커스텀 마커 아이콘/오버레이로 구현.
- [ ] **경로 폴리라인**: 촬영 시각(UTC 정규화, 10) 순으로 스톱 연결. AI 구간은 점선/반투명(프로토타입 `segs`의 dash·opacity 규칙).
- [ ] **지도/위성 토글**(프로토타입 `setMapView`/`setSatView`): 상단 세그먼트. 위성 뷰에서 상단 UI 대비(상태바·바 색) 보정.
- [ ] 초기 카메라: 전체 스톱이 보이도록 `LatLngBounds` fit.

## 상단바·위치미상 진입 (프로토타입)
- [ ] 상단바: 뒤로(→Home) · 여행 제목("2024 파리 여행") · 지도/위성 토글(반투명 blur pill).
- [ ] "위치 미상 N" 배지(다크 반투명 + 노란 아이콘) → drawer(13에서 구현, 여기선 배지·카운트만).
- [ ] `PLACED`만 지도에 표시. `NAME_ONLY`/`UNKNOWN`은 지도 제외(위치미상 그룹), `NO_TIME`은 핀 표시하되 경로 순서 제외(§4.6).

## 데이터 소스
- [ ] 10 세션 결과 또는 04 저장 여행(15)에서 스톱 목록 로드. 프로토타입 `STOPS()` 형상(id·name·city·좌표·src·time·extra) 참조.
- [ ] 같은 위치 다수 사진의 "+N장"(프로토타입 `extra`) 집계.

## 핵심 결정·제약
- **핵심 가치는 이 2D 경로로 완결**(§4.4). 14(3D) 없이도 완제품이어야 함.
- 프로토타입의 CSS 지도(가짜 SVG 타일·카메라 transform)는 이식하지 않는다 — 실제 Maps SDK 타일·카메라 사용.
- **지도 타일은 네트워크 필요**(§5 오프라인): 연결 없으면 빈/실패 타일 위 폴리라인만 — 15에서 안내.

## 완료 조건 (DoD)
- [ ] 실제 Maps 타일 위에 스톱 핀·시각순 경로가 정확히 렌더.
- [ ] GPS/AI 핀이 시각적으로 구분되고 AI에 "근사 위치" 표식.
- [ ] 지도/위성 토글 동작, 위성에서 상단 UI 가독성 확보.
- [ ] 위치 미상 카운트·배지 표시, 분류별 표시 규칙 준수.
- [ ] 초기 카메라가 전체 경로를 담음.

## 리스크·주의
- Maps API 키·결제·SHA 등록 셋업 필요(01 문서화와 연계).
- 커스텀 마커(점선/반투명) 렌더 방식(BitmapDescriptor vs Ground overlay) 성능 검토.
- 좌표 없는 분류(NAME_ONLY/UNKNOWN)를 실수로 (0,0)에 찍지 않도록 방어.
