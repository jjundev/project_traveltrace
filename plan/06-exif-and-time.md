# 06 · EXIF 추출 · UTC 시각 정규화 · 타임존 처리

> 각 사진의 원본에서 GPS·촬영 시각 EXIF를 로컬로 읽고, 촬영 시각을 UTC로 정규화해 정렬 가능한 형태로 만든다.

> **상태: ⬜ 미착수.**

- **Epic**: Analysis
- **Depends on**: 04, 05
- **PRD**: §4.2 위치 우선순위·시각 정규화, §9 #7·#8, §8(EXIF 타임존 부재)
- **Prototype**: 타임존 확인 시트(`showTz`, "이 여행, 파리 기준이 맞죠?")

## 목표
- GPS 있는 사진 → 좌표 확보(AI 호출 없음).
- 촬영 시각 → UTC 정규화 후 안정 정렬 키 생성.
- 오프셋·사용자 타임존 부재 시 폴백 규칙 적용.

## 범위
- **In**: 원본 EXIF 접근(권한·`setRequireOriginal`), GPS/시각 태그 파싱, UTC 정규화, 타임존 확정 시트·폴백, 동일 초 tiebreak.
- **Out**: AI 인식(08), 좌표화(09), 파이프라인 오케스트레이션(10), 실제 시트 UI 배치(11에서 Analyze에 통합 — 로직·계약은 여기).

## 원본 GPS 추출 (§4.2-1)
- [ ] `ACCESS_MEDIA_LOCATION` + `MediaStore.setRequireOriginal(uri)`로 **원본** 스트림 획득(scoped storage는 기본적으로 위치 EXIF를 가림).
- [ ] `androidx.exifinterface`로 위경도 파싱. 유효 GPS면 `source=GPS`, 좌표 저장(04), **AI 호출 대상에서 제외**.
- [ ] GPS 없음 → `source` 미정, AI 대상(08·10)으로 표시.

## 시각 정규화 (§4.2 시각 정규화 — 핵심)
- [ ] `DateTimeOriginal` + `OffsetTimeOriginal`(있으면) → **UTC 정규화** 후 정렬.
- [ ] 오프셋 태그 없음 → 사용자에게 **여행 기준 타임존 1개** 지정받음(타임존 확인 시트).
- [ ] **무타임존 폴백**: 오프셋도 없고 사용자 지정도 없으면 **기기 현재 타임존을 기본 적용** + "정확한 순서를 위해 여행 타임존을 지정하세요" 경고 **1회** 표시(분석은 **차단하지 않음**).
- [ ] 동일 초단위 타임스탬프(연사) → **파일명/식별자 순 안정 tiebreak**.
- [ ] 촬영 시각 자체가 없는 사진 → `classification=NO_TIME`(좌표는 있으면 유지, 경로 순서에서는 제외 — §4.6).

## 타임존 확인 시트 계약 (프로토타입 `showTz`)
- [ ] 트리거: 오프셋 태그 없는 사진이 존재할 때 분석 시작 직후 1회.
- [ ] 기본 추정 도시/타임존 제시("파리 기준이 맞죠?") — GPS가 일부라도 있으면 그 좌표에서 타임존 추정, 없으면 기기 타임존.
- [ ] `confirmTz`(그대로) / `changeTz`(다른 도시 선택 — v1은 스텁 가능, 최소 타임존 목록) → 확정 `timeZoneId`를 Trip에 저장(04).
- [ ] 이 시트는 **분석을 게이팅**하되, 취소/무시 시 폴백 규칙으로 진행.

## 핵심 결정·제약
- **좌표를 AI로 만들지 않는다**는 원칙과 무관하게, 06은 EXIF GPS만 다룸. AI 경로는 08~10.
- 다중 타임존 여행(오프셋 없음)은 **v1 허용 한계**(§8): 단일 `timeZoneId` 기준 정렬, 경계/DST 부근 순서 오차 감수.
- 무타임존 폴백은 경고만, **절대 분석을 막지 않는다**.

## 완료 조건 (DoD)
- [ ] GPS 있는 원본에서 좌표가 실제로 추출됨(권한·`setRequireOriginal` 검증). GPS 가린 파생본과 비교 테스트.
- [ ] 오프셋 有/無/사용자 지정/기기 폴백 4경로가 올바른 UTC 정렬 키를 만든다.
- [ ] 연사(동일 초) 사진이 안정적으로 정렬됨.
- [ ] 타임존 시트가 오프셋 부재 시에만 뜨고, 결과가 Trip에 저장됨.

## 리스크·주의
- HEIC/RAW 등 비-JPEG의 EXIF 파싱 편차 — 포맷별 검증 필요. (재인코딩·스트립은 07에서, 읽기는 여기.)
- `setRequireOriginal` 실패/권한 부분 상황에서 GPS가 조용히 누락되면 다수가 AI로 흘러 비용↑ — 실패를 감지·로깅.
- 타임존 추정(좌표→tz)에 별도 라이브러리 필요할 수 있음(오프라인 tz 데이터). 의존성 리뷰.
