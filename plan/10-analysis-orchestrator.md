# 10 · 분석 오케스트레이터 (우선순위 · 동시성 · 재시도 · 비용 상한 · 분류)

> 선택한 사진들을 위치 우선순위 규칙에 따라 처리하고, 동시성·타임아웃·재시도·비용 상한을 강제하며, 진행률과 3종 분류를 산출해 DB에 저장하는 중심 파이프라인.

- **Epic**: Analysis
- **Depends on**: 06, 07, 08, 09
- **PRD**: §4.2 우선순위, §4.6 분류, §4.8 비용/동시성, §5, §9 #5·#12·#13
- **Prototype**: `runAnalyze`(진행 스텝), `done`/"경로 6 · 위치 미상 5"

## 목표
사진 리스트를 받아 각 사진의 최종 위치·분류를 결정하고, 성능·비용 정책 안에서 완주하며, 결과를 04에 저장하고 진행 상태를 11에 노출.

## 위치 우선순위 (§4.2 — 핵심 순서)
1. **EXIF GPS 존재** → 그 좌표 사용, **AI 호출 없음** (06).
2. **GPS 없음** → 07 파이프라인(EXIF 로컬읽기→다운스케일→업로드) → 08 AI 이름 추론 → 09 지오코딩.
3. **GPS도 AI도 실패** → `UNKNOWN`(위치 미상).
- [ ] 각 사진 진입 전 **04 캐시 확인**((`_ID`+해시)) → hit면 전체 스킵.

## 분류 산출 (§4.6 — 3종 + 시각없음)
- [ ] `PLACED`: 좌표 확보(GPS 또는 AI+지오코딩 성공). 지도·경로에 표시.
- [ ] `NAME_ONLY`: 지오코딩/disambiguation 실패(09). 위치 미상과 별도, 이름 노출.
- [ ] `UNKNOWN`: GPS·AI 모두 실패. 지도/경로 제외, "위치 미상" 섹션.
- [ ] `NO_TIME`: 위치는 있으나 촬영 시각 없음(06). 경로 순서 제외, 핀은 표시(그룹/순서 끝).

## 동시성·재시도·타임아웃 (§4.8 — 수치 확정)
- [ ] 동시 Vision/지오코딩 콜 **최대 4건**(ExecutorService 고정 풀 + 세마포어/제한 큐).
- [ ] 콜당 **타임아웃 30초**(OkHttp timeout).
- [ ] 실패 시 **재시도 최대 2회**, 지수 백오프 **1s→2s→4s + 지터**.
- [ ] **429/할당량** 응답 → 백오프 연장 + 사용자 안내(11 토스트/배너).
- [ ] 취소 지원: 사용자가 Analyze 이탈 시 진행 중 콜 중단(03·11 훅).

## 비용 상한 (§4.8, §5, §9 #5 — 핵심)
- [ ] **여행당 API 콜/비용 상한**을 앱 내에서 설정·집계(콘솔 quota와 별개). 상한 도달 시 **분석 중단·안내**.
- [ ] 집계 대상: Vision 콜, Places/Geocoding 콜(, GA 후 3D 타일 — 14 연계).
- [ ] **한계 명시**: 앱측 상한은 도난 키를 못 막음(콘솔 quota cap이 유일한 피해 제한, §5). 상한은 정상 사용자 비용 통제용.
- [ ] 진행 집계를 Trip `costSpent`(04)에 저장.

## 진행 상태 (§4.8)
- [ ] "N / 총장수 분석 중" 진행률 + 현재 인식 항목 텍스트(프로토타입 `recogName`). 11에 노출.
- [ ] 완료 시 요약: 경로 스톱 수 · 위치 미상 수(프로토타입 "경로 6 · 위치 미상 5").

## 작업 항목
- [ ] `AnalysisOrchestrator`(ExecutorService 기반): 캐시확인 → 우선순위 라우팅 → 병렬 제한 → 재시도 → 분류 → 04 저장 → 진행 콜백.
- [ ] 정렬: `PLACED`/시각 있는 사진을 UTC 정규화(06)로 정렬해 경로 구성.
- [ ] 취소·재개·상한 도달·오프라인 상태를 상태 머신으로 관리.
- [ ] 결과를 Trip으로 확정(15 저장 연계) 또는 임시 세션 결과로 보관.

## 완료 조건 (DoD)
- [ ] GPS 사진은 AI 호출 0회로 처리됨(비용 로그로 확인).
- [ ] 동시 4·타임아웃 30s·재시도 2회·백오프+지터가 실제로 적용됨.
- [ ] 여행당 상한 도달 시 분석이 안전하게 중단되고 사용자 안내.
- [ ] 3종+시각없음 분류가 정확히 산출·저장됨.
- [ ] 캐시 hit 시 해당 사진의 네트워크 콜 0회.
- [ ] 취소 시 진행 중 콜이 실제로 중단됨.
