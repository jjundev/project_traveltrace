# 11 · 분석 진행 화면 (Analyze)

> 오케스트레이터(10)의 진행을 시각화하는 화면. 타임존 확인 시트, 진행률·인식 텍스트, 완료 요약, 지도 전환 CTA, 비용 상한/오류 안내.

> **상태: 🟡 UI만 완료.** 진행 카드·완료 전환·타임존 시트가 렌더되나 진행률은 41/82 **고정값**
> (`AnalysisViewModel.PREVIEW_ANALYZED`)이다. 10이 없으므로 실제 바인딩·취소·상한/429/오프라인 안내는 미착수.
> 타임존 시트도 **무조건 표시**되며 조건부 로직(06 계약)이 없고, `onTimezoneConfirmed()`는 빈 메서드다.

- **Epic**: Analysis UI
- **Depends on**: 03, 10 (표시 로직은 06 타임존 계약도 소비)
- **PRD**: §4.8 진행/비용, §4.2 타임존 시트
- **Prototype**: ANALYZE 화면(`analyzing`/`done`, 진행 바, `showTz` 시트, "지도에서 여행 보기")

## 목표
사용자가 분석 진행을 신뢰감 있게 보고, 필요한 확인(타임존)을 하고, 완료 후 지도로 넘어간다.

## 범위
- **In**: 진행 카드 UI, 스피너/진행바/카운터, 현재 인식 항목 텍스트, 타임존 시트 표시, 완료 요약, 지도 전환 CTA, 상한·429·오류·오프라인 안내(토스트/배너), 취소(뒤로).
- **Out**: 분석 로직(10), 타임존 결정 규칙(06), 지도(12).

## UI 상태 (프로토타입 ANALYZE)
- [ ] **분석 중(`analyzing`)**: 스피너 + "사진 분석 중" + "N / 총장수"(파란 강조) + 진행바(`progressPct`) + 위치 아이콘 + 현재 인식 텍스트(`recog`, 10에서 공급).
- [x] **완료(`done`)**: 녹색 체크 + "분석 완료" + 요약("경로 N · 위치 미상 M") + 하단 "지도에서 여행 보기" CTA(→ Map, 12). — 렌더·전환 O (수치는 픽스처)
- [ ] 좌상단 뒤로 버튼(반투명 원형) → Home(취소, 10 취소 훅 호출).
- [x] 배경: 프로토타입은 지도 레이어 위에 카드가 뜸 — 네이티브에선 정적 배경(지도 프리뷰는 선택, 필수 아님). — `bg_base` 채택

## 타임존 확인 시트 (프로토타입 `showTz` → 06 계약)
- [ ] 분석 시작 직후, 오프셋 부재 사진이 있으면 바텀시트 표시("이 여행, OO 기준이 맞죠?").
- [ ] "네, 맞아요"(`confirmTz`) → 확정 후 분석 진행. "다른 도시 선택"(`changeTz`) → 타임존 선택(v1 최소 목록 or 스텁 + 폴백).
- [ ] 시트 결정은 06 로직으로 위임하고, 화면은 표시·입력만.

## 비용·오류·오프라인 안내 (§4.8)
- [ ] 여행당 상한 도달 → 분석 중단 배너 + 재개/종료 선택.
- [ ] 429/할당량 → "잠시 후 다시" 안내(10 백오프와 연동).
- [ ] 네트워크 없음 → 안내(분석은 네트워크 필요; 저장 여행 재생은 별개 — 15).

## 완료 조건 (DoD)
- [ ] 진행률·카운터·인식 텍스트가 10의 실제 진행과 동기화.
- [ ] 타임존 시트가 조건부로 뜨고 결과가 분석에 반영.
- [ ] 완료 요약 수치가 10 분류 결과와 일치.
- [ ] 뒤로가기 시 분석이 실제로 취소되고 리소스 정리.
- [ ] 상한/429/오프라인 각각 사용자 안내가 표시.

## 리스크·주의
- 진행 콜백 스레드 → UI 스레드 마샬링(ExecutorService → main). 갱신 폭주 시 throttle.
- 프로토타입의 가짜 진행(`+3씩 90ms`)을 흉내 내지 말 것 — 실제 10 진행에 바인딩.
- 완료 후 지도 전환 시 결과 핸들(tripId/세션) 전달 계약(03) 준수.
