# 13 · 경로 리플레이 · 슬라이드쇼 (컨트롤 · 타임라인 · 상영모드 · 위치 미상)

> 2D 지도 위에서 촬영 시각순으로 카메라가 스톱을 순회하며 사진 카드를 보여주는 자동/수동 리플레이. 속도·타임라인·상영모드·위치 미상 처리 포함.

> **상태: 🟡 UI만 완료 — 재생 로직 0.** 하단시트·타임라인 스크러버(커스텀 뷰)·상영모드 오버레이·
> 위치미상 drawer가 전부 렌더되고 컨트롤도 눌린다. 그러나 `togglePlay()`는 **아이콘만 바꾸고**
> 카메라·인덱스·타이머 무엇도 움직이지 않는다. detach도 미구현.
> **이 에픽의 나머지 절반이 제품의 핵심 가치**다(슬라이스 S2).

- **Epic**: Map (핵심)
- **Depends on**: 12
- **PRD**: §4.5 리플레이, §4.6, §9 #9·#13
- **Prototype**: MAP 하단시트(사진 배너·타임라인·재생컨트롤·속도), 상영모드(`cinema`), 위치미상 drawer, `startFlight`/`glideTo`/`schedule`/`freezeFlight`

## 목표
프로토타입의 리플레이 경험을 네이티브로 재현: 부드러운 카메라 이동 + 도착 시 사진 카드 팝 + 자동/수동 제어 + 속도 프리셋 + 상영모드.

## 범위
- **In**: 하단시트(사진 배너·GPS/근사 배지·타임라인 스크러버·재생/일시정지/이전/다음·속도 프리셋), 자동 재생 순회, 카메라 이동 연출(2D 팬/줌), 도착 팝 애니메이션, 상영모드, 위치미상 drawer, 핀 "빼기"(detach), 토스트.
- **Out**: 3D 비행(14 — 여기선 2D 카메라 연출), 지도 기본 렌더(12), 저장(15).

## 자동 재생 (§4.5, 프로토타입 `schedule`/`glideTo`)
- [ ] 스톱을 시각순 순회: 카메라를 다음 스톱으로 이동 → 도착 시 사진 카드 표시 → 일정 dwell 후 다음.
- [ ] 카메라 이동은 **2D 팬/줌**(표준 Maps `animateCamera`). 프로토타입의 줌아웃 아크·도착 팝 **연출 의도**를 살리되 CSS transform 코드는 이식 안 함.
- [ ] dwell 시간은 속도 프리셋 연동(프로토타입 `viewDwell`: relaxed 2800 / normal 1800 / fast 1100ms).

## 수동 제어 (§4.5, 프로토타입)
- [ ] 재생/일시정지(중앙 큰 버튼), 이전/다음(양옆). **일시정지 시 이동 중이면 "공중 정지" 후 재개 시 잔여 구간 이어감**(프로토타입 `freezeFlight`/`resumeFlight` — 2D에선 진행 중 애니메이션 중단·재개로 구현).
- [ ] 타임라인 스크러버: 스톱별 도트(현재/완료/AI 점선 구분), 탭 시 해당 스톱으로 점프(`jumpTo`). ← **부분**: `TimelineScrubberView`가 도트 렌더·히트테스트까지 O, `jumpTo` 연결 X
- [ ] 이전/다음 경계에서 비활성 색 처리(`prevColor`/`nextColor`).
- [ ] 속도 프리셋: 느긋이/보통/빠르게 세그먼트(프로토타입 `setRelaxed`/`setNormalSpeed`/`setFastSpeed`), 기본값은 진입 인자(프로토타입 `startSpeed`).

## 사진 카드 배너 (프로토타입 하단시트 상단)
- [ ] 현재 스톱 사진 배너: 이름·시각·"i/총" 인덱스, GPS 배지(파랑) 또는 "근사 위치" 배지(회색 점선) + "빼기"(detach).
- [ ] 같은 위치 다수면 "+N장"(프로토타입 `curExtra`).
- [ ] 도착 팝 애니메이션(프로토타입 `playPop`: scale/opacity 스프링).

## 상영 모드 (프로토타입 `cinema`)
- [ ] 컨트롤 숨기고 사진을 크게(전체 몰입). 화면 탭 시 컨트롤 복귀 안내.
- [ ] 상영모드에서 카메라 줌 base 상향(프로토타입 `zBase` 2.0→2.4 의도).

## 위치 미상 처리 (§4.6, 프로토타입 `showUnknown` drawer)
- [x] "위치 미상 N" 배지(12) → drawer: `UNKNOWN` 사진 그리드 + 설명("GPS도 장소도 못 알아낸 사진…시각 있으면 흐름에, 나머지는 에필로그"). — `UnknownPhotosSheetFragment` (그리드는 단색 View)
- [ ] 핀 "빼기"(`detach`): 리플레이에서 특정 스톱을 위치 미상으로 이동(경로 재구성) + 토스트("핀을 위치 미상으로 옮겼어요").
- [ ] `NAME_ONLY`(이름만) 표시(이름 노출, 향후 수동 핀 대상)와 `NO_TIME`(시각 없음, 순서 끝 그룹) 구분.

## 상태 관리 (프로토타입 로직 → 네이티브)
- [ ] 재생 상태(playing/active/moving), 타이머·애니메이션 취소(`clearTimers`/`clearMove`), 화면 이탈/뒤로 시 정리.
- [ ] detach 목록·현재 인덱스의 SoT를 04와 합의(저장 여행 재생 일관성, 04 리스크 항목).

## 완료 조건 (DoD)
- [ ] 자동 재생이 시각순으로 스톱을 순회하며 사진 카드를 팝으로 표시.
- [ ] 일시정지→재개가 이동 중에도 자연스럽게 이어짐.
- [ ] 타임라인 점프·이전/다음·속도 프리셋 동작.
- [ ] 상영모드 진입/이탈, 위치미상 drawer·detach·토스트 동작.
- [ ] 화면 이탈 시 타이머·애니메이션이 누수 없이 정리.

## 리스크·주의
- 프로토타입 rAF 경쟁 스케줄러/공중정지 로직은 CSS 3D용 — 네이티브에선 Maps 카메라 애니메이션의 중단·재개 API로 등가 구현(그대로 포팅 금지).
- 재생 상태 머신은 10/12/15와 얽힘 — 경계 명확히(누수·중복 애니메이션 방지).
- detach로 경로가 바뀌면 타임라인·인덱스 재계산 일관성 유지.
