# 14 · 3D 비행 (best-effort) — Maps 3D SDK · 강등 계약

> 가용 시 3D로 기울어진 카메라가 스톱 사이를 비행하는 연출. 불가하면 12/13의 2D 리플레이로 자동 강등. **3D 미가용은 오류가 아니라 정상 강등.**

- **Epic**: Map (부가 · best-effort)
- **Depends on**: 12, 13
- **PRD**: §4.4 3D 강등 계약, §8, §9 #10
- **Prototype**: `startFlight`(tilt/rotate swoop), 위성 플라이오버, `flyVignette`

## 목표
13의 리플레이에 3D 비행 연출을 얹되, **2D 완제품(12·13) 위에 얹는 옵션**으로만 구현. 실패 시 사용자를 막지 않고 2D로 내려간다.

## 범위
- **In**: Maps 3D SDK(Experimental) 초기화, `flyTo`/`flyAround` 카메라 경로로 스톱 순회, 강등 감지·전환·1회 고지, 3D 비용 집계·정책, sideload 위험 고지.
- **Out**: 2D 리플레이 로직(13 — 강등 시 그대로 재사용), 핀/경로 데이터(12).

## 3D 렌더 (§4.4)
- [ ] **Maps 3D SDK for Android (Experimental Preview)**로 3D 뷰 초기화. `flyTo`/`flyAround` 카메라 경로로 13의 순회 스텝을 3D 비행으로 대체.
- [ ] 프로토타입의 tilt/rotate/줌아웃 아크·비네트 **연출 의도**를 3D 카메라 파라미터로 재현(CSS 코드 이식 아님).
- [ ] 13의 재생 상태 머신(재생/일시정지/이전/다음/속도)을 3D 카메라에 그대로 연결.

## 강등 계약 (§4.4 — 핵심, #3)
- [ ] 다음 중 하나라도 발생하면 **자동으로 표준 Maps 2D 폴리라인 리플레이(12·13)로 전환**하고 **1회 고지**:
  - 3D SDK 초기화 실패 / 기기·API 미지원
  - Experimental Preview 종료 또는 GA 과금 전환 감지
- [ ] 3D는 **best-effort 부가 기능**. 3D 미가용 = **정상 강등**(오류 UI·크래시 금지).
- [ ] 강등 경로가 실제로 12·13을 재사용하도록 설계(3D/2D가 동일 재생 인터페이스 뒤).

## 비용·업데이트 정책 (§4.4, §5)
- [ ] **GA 과금 전환 대비**: 3D 타일 호출 비용을 10 여행당 비용 집계에 포함하거나, **GA 후 3D 기본 OFF** 정책을 사전 결정(§5 비용 상한과 충돌 방지). 둘 중 택1을 리뷰에서 확정하고 여기 역기록.
- [ ] **sideload 위험 고지**: 자동 업데이트 경로가 없어 Experimental API breaking change 시 수동 재설치 전까지 3D가 깨질 수 있음을 **README·앱 내 고지**.

## 완료 조건 (DoD)
- [ ] 지원 기기에서 3D 비행이 13의 재생 컨트롤과 연동되어 동작.
- [ ] 초기화 실패/미지원/Preview 종료 감지 시 **자동으로 2D로 강등** + 1회 고지, 크래시·막힘 없음.
- [ ] 3D 없이도(강등 상태) 제품이 완결(12·13만으로 완주).
- [ ] 3D 타일 비용 집계 또는 GA OFF 정책 중 택1이 구현·문서화.
- [ ] sideload 3D 취약 고지가 README·앱에 존재.

## 리스크·주의
- Experimental API의 breaking change/철회/GA 과금은 상시 위험(§8) — 강등 감지 로직을 방어적으로.
- 3D를 M3(핵심)에 끼우지 말 것 — 00 마일스톤대로 M4. 3D가 2D 완결선을 흔들면 안 됨.
- 3D/2D 재생 인터페이스가 갈라지면 13 상태 머신이 이중화됨 — 공통 추상 뒤에 두기.
